# Analyzer of Ratings and Number Statistics in C++

Консольна програма на **C++** для статистичного аналізу чисел та оцінок з інтерактивним меню, валідацією вводу та декомпозицією логіки на окремі функції.

## Можливості (v2.1)

* **Введення та перевірка даних:** безпечне зчитування кількості елементів (від `1` до `100`) та дробових/цілих чисел (`double`) з очищенням буфера вводу при помилках.
* **Базова статистика:** обчислення кількості елементів, суми (`std::accumulate`) та середнього арифметичного.
* **Медіана:** коректний розрахунок медіани для непарної та парної кількості чисел на відсортованому векторі.
* **Мода (найбільш часте значення):** пошук найчастішого числа з частотою повторень, підтримка кількох мод при рівній частоті та коректна обробка випадку, коли всі числа унікальні.
* **Орієнтир за 12-бальною шкалою:** текстова оцінка середнього балу (*Початковий*, *Середній*, *Достатній*, *Високий рівень*).
* **Екстремуми та порівняння із середнім:** пошук мінімуму і максимуму (`std::min_element`, `std::max_element`), а також підрахунок значень вище, нижче та рівних середньому.
* **Сортування та повторний запуск:** вивід чисел за зростанням (`std::sort`) без зміни початкового порядку та можливість проаналізувати кілька наборів чисел поспіль без перезапуску програми.

## Основні поняття та бібліотеки C++

* `std::vector` для зберігання вибірки та відсортованої копії
* `<algorithm>` (`std::sort`, `std::min_element`, `std::max_element`)
* `<numeric>` (`std::accumulate`)
* `<iomanip>` (`std::fixed`, `std::setprecision(2)`)
* `<limits>` (`std::numeric_limits`) для очищення потоку `std::cin`
* Розбиття коду на функції (`clearInput`, `readIntInRange`, `readDouble`, `calculateMedian`, `findModes`, `getGradeLevel12`, `printStats`)
